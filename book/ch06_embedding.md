# Chapter 06. 임베딩

- **Text Vectorization**: 토큰화된 텍스트를 숫자로 변환하는 방법
  - **One-Hot Encoding**: 문서에 등장하는 각 단어를 고유한 색인 값으로 매핑 후, 해당 색인의 위치를 1로 표시하고 나머지는 모두 0으로 표시하는 방식
  - **Count Vectorization**: 문서에서 단어의 빈도를 세어 해당 단어의 빈도를 벡터로 표현하는 방식
  - 장점: 단어나 문장을 벡터 형태로 변환하기 쉽다
  - 단점: 벡터의 Sparsity가 크다. 차원의 저주. 입력 텍스트의 의미를 내포하지 않는다

- **Word Embedding**: 단어를 고정된 길이의 실수 벡터로 표현하는 방법. 단어의 의미를 벡터 공간에서 다른 단어와의 상대적 위치로 표현해 단어간의 관계를 추론
  - 단점: 고정된 임베딩을 학습하기 때문에 다의어나 문맥 정보를 다루기 어려움

- **Dynamic Embedding**: 인공 신경망을 활용한 방법

- **Language Model**: 입력된 문장으로 각 문장을 생성할 수 있는 확률을 계산하는 모델
  - 주어진 문장을 바탕으로 문맥을 이해하고 문장 구성에 대한 예측을 수행
  - 활용 분야: 자동 번역, 음성 인식, 텍스트 요약
  - **Autoregressive Language Model**: 입력된 문장들의 조건부 확률을 이용해 다음에 올 단어를 예측
    - Chain rule for conditional probability: 하나의 사건이 일어날 확률을 다른 사건들의 조건부 확률을 이용해 계산하는 방식
  - **Statical Langauge Model**: 언어의 통계적 구조를 이용해 문장이나 단어의 시퀀스를 생성하거나 분석.
    - Markov Chain: 빈도 기반의 조건부 확률 모델 중하나로 이전 상태와 현재 상태 간의 전이 활률을 이용해 다음 상태를 예측
    - Data sparsity 문제: 관측한 적인 없는 데이터를 예측하지 못하는 문제

- **N-gram**: 텍스트에서 N개의 연속된 단어 시퀀스를 하나의 단위로 취급하여 특정 단어 시퀀스가 등장할 확률을 추정
  - 연속된 N개의 단어를 하나의 단위로 취급하여 추론하는 모델. 모든 토큰을 사용하지 않고 N-1개의 토큰만을 고려해 확률을 계산
  - N이 1이면 Unigram, 2이면 Bigram, 3이면 Trigram이라고 명명
  - 장점: 작은 규모의 데이터세트에서 연속된 문자열 패턴ㅇ르 분석하는 데 큰 효과를 보인다. 관용적 표현 분석에도 활용된다
  - 활용 분야: 단어의 순서가 중요한 자연어 처리 작업 및 문장려 패턴 분석에 활용

## TF-IDF
- TF-IDF(Term Frequency-Inverse Document Frequency): 텍스트 문서에서 특정 단어의 중요도를 계산하는 방법. 문서 내에서 단어의 중요도를 평가하는 데 사용되는 통계적인 가중치를 의미. BoW에 가중치를 부여하는 방법
  - BoW(Bag-of-Words): 문서나 문장을 단어의 집합으로 표현하는 방법. 문서나 문장에 등장하는 단어의 중복을 허용해 빈도를 기록
- Term Frequency: 문서 내어서 특정 단어의 빈도수를 나타내는 값. 단어의 상대적인 중요도를 측정하는데 사용. 
- Document Frequency: 한 단어가 얼마나 많은 문서에 나타나는지를 의미. 단어가 몇 개의 문서에서 등장하는지 계산
  - DF값이 높다면 일반적으로 널리 사용되며 중요도가 낮을 수 있다
  - DF값이 낮다면 특정 단어가 적은 수의 문서에만 등장한다는 의미로 중요도가 높을 수 있다
- IDF(Inverse Document Frequency): 전체 문서 수를 문서 빈도로 나눈 다음에 로그를 취한 값을 의미. 문서 내에서 특정 단어가 얼마나 중요한지 표현
  - IDF값이 커질수록 단어의 빈도 수가 적음
  - IDF(t,D) = log(count(D)/(1 + DF(t,D))). 분모가 0이 되는 걸 방지하기 위해 1을 더함
- TF-IDF는 단어 빈도와 역문서 빈도를 곱한 값으로 사용.
  - TF-IDF(t,d,D) = TF(t,d) x IDF(t,d)
